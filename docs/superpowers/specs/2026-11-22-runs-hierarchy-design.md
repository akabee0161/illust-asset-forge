# runs/ の階層分け 設計書

作成: 2026-11-22。作成時点のログで、後から更新しない。最新の状態は `README.md`・`CLAUDE.md`。

## 1. 目的と背景

Drive の `illust-asset-forge/runs/` を開くと、日時のフォルダが並ぶだけで、どれがどのキャラクターのどの種類の絵かが分からない（依頼者がスマホの Drive で候補を探すときの不満）。キャラクターと種類で分けて、探しやすくする。

今のコードの事実:

- 1 フォルダ = 生成 1 回分。`generate(["ally05", "ally06"], ...)` は 2 人分が同じ日時のフォルダに混ざる
- 種類（顔・表情・全身・画風の見比べ）は、ファイル名にしか出ていない（`<id>_face_<表情>_<seed>.png`、`<id>_<型>_<画風>_<seed>.png`）
- 採用した絵は、すでに `selected/<id>/` にキャラクター別でまとまっている。分けたいのは `runs/` だけ
- 候補を開き直す `P.pick(forge, run_id=None)` は、最新の 1 フォルダを開く

## 2. ゴール・ゴールでないこと

ゴール:

- Drive の `runs/` を開いたとき、キャラクター → 種類 → 日時の順にたどれる
- 候補を開き直すとき、キャラクター・種類で絞れる
- 今ある古い `runs/<日時>/` の候補も、今までどおり開ける

ゴールでないこと（依頼者が決めた範囲外）:

- 古いフォルダの移行・削除（そのまま残す）
- `selected/`・`packs/`・`intake`・`export` の変更

失敗とみなすこと:

- 古い候補が開けなくなる
- 複数キャラクターを一度に作ったとき、一部のキャラクターの候補が、開き直しの画面から漏れる

## 3. 制約

- ファイル名・PNG の条件のキー（`run_id` は日時のまま）は変えない
- `forge.adopt("<ファイル名>")` は、今までどおり全部の run から新しい順に探す
- 設定の誤り・入力の誤りは `ConfigError`（何をすればよいかを書く）

## 4. 方式の比較（依頼者が A を選択）

| 案 | 中身 | 良い点 | 弱い点 |
|---|---|---|---|
| **A（採用）** | 保存先だけ新しい階層にし、探す側は `runs/` の下を全部たどる | 古い候補も、今のノートブックの書き方もそのまま使える | 探す側が 2 種類の階層（新旧）を読む |
| B | 新しい階層専用に作り直す | 仕組みがそろう | 古い候補が開けなくなる。移行作業が要る |

## 5. 決まった作り

### 5.1 保存先

`runs/<キャラクターID>/<種類>/<日時>/<ファイル名>.png`

| 種類 | 作るもの |
|---|---|
| `face` | `generate(..., "face")` |
| `face-<表情>` | `inpaint(..., 表情)`（例: `face-hurt`） |
| `fullbody` | `generate(..., "fullbody")` |
| `styles` | `compare_styles(..., "face")`。型が顔以外のときは `styles-<型>` |

- 複数キャラクターを一度に作ったときは、各キャラクターのフォルダに、同じ日時（同じ `run_id`）で分けて入れる
- 中断のメッセージ（「N 枚が … に保存済み」）は、保存先が複数に分かれうるので、`runs/` の場所を出す

### 5.2 探す側

- `run_ids`: 日時の一覧（重複なし・古い順）。新しい階層（`runs/<id>/<種類>/<日時>/`）と、古い階層（`runs/<日時>/`。名前が `YYYYmmdd_HHMMSS` のもの）の両方から集める
- `run_paths(runs_dir, run_id=None, *, char=None, kind=None)`: 条件に合う run のうち、日時が最新のものの PNG を、パス順に返す。`run_id` を渡すとその日時。複数のフォルダにまたがる日時（複数キャラクター）は、全部まとめて返す
- `char`・`kind` を渡したときは、新しい階層だけが対象（古い階層は、キャラクターも種類もフォルダから分からないため）。古い候補は、`run_id` を渡して開く
- `find_candidate`: ファイル名は、全部の run から新しい順に探す（新旧の階層とも）。シードは、最新の日時から探す（今までどおり）
- 条件に合う候補が無いときは、あるキャラクター・種類を挙げて `ConfigError`

### 5.3 ノートブックの書き方

```
P.pick(forge, char="ally05", kind="face")                         # その条件で最新の日時
P.pick(forge, char="ally05", kind="face", run_id="20261122_040448")
P.pick(forge, run_id=None)                                        # 今までどおり、最新の日時の全部
```

`P.pick(forge, paths)` の書き方は変えない。

### 5.4 ドキュメント

README の置き場の表・候補を開き直す説明・ノートブックの「候補を開き直す」のセルを直す。
