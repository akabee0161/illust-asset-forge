# 切り出しと背景消し（cutout） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 書き出しがテンプレートごとの `cutouts` に従って切り抜き・背景を透明にし、マスクを Modal の CPU で作り、承認用ページと候補のページで背景を消した絵を見せられるようにする。

**Architecture:** 設定（`config.py` の `Cutout`）→ マスク（`matte.py`・`modal_app.matte_remote`・`cloud matte`）→ 描画（新しい `cutout.py`）→ 書き出し（`export.py` が `cutouts` を使い `params.json` に記録）→ 承認用ページ（新しい `cutout_review.py`）の順に積む。候補のページ（`review_page.py`）と `cloud generate/page/merge` は、候補のマスクを先に作ってから組み立てる。

**Tech Stack:** Python 3.12、Pillow、PyYAML、pytest。Modal（`modal_app.py` の中だけ）。anime-seg の `isnetis.onnx`（Modal の中だけ）。

**Spec:** `docs/superpowers/specs/2026-11-24-cutout-design.md`

**移植元:** コピー先（各作品のリポジトリの中にある forge のコピー。以下「コピー」）。差分はコピー先のリポジトリで `git diff cb9c6da..a528105 -- illust-asset-forge/src illust-asset-forge/tests`。コピーのファイルで丸ごと上書きせず、forge の今のコードに足す。コピーのフォルダは変えない。

## Global Constraints

- 背景除去のモデルをこのサーバーで動かさない。onnxruntime・numpy を `.venv` にも `pyproject.toml` の依存にも入れない。`isnet_mask` の中と `matte_remote` の中でだけ import する
- テストから本物の Modal を呼ばない（Task 1 の守り）。modal は `modal_app.py` の中でだけ import し、`cloud.py` は使う関数の中で `from artgen import modal_app`
- 生成の GPU は T4 だけ。マスクは `cpu=2, memory=4096, timeout=1800`
- モデル: `MODEL_REPO = "skytnt/anime-seg"`、`MODEL_FILE = "isnetis.onnx"`、`MODEL_SHA256 = "f15622d853e8260172812b657053460e20806f04b9e05147d49af7bed31a6e99"`、`MODEL_INPUT = 1024`、`CANDIDATE_BATCH = 40`、`HARD_LOW = 128`、`HARD_HIGH = 200`
- マスクの image の版: `onnxruntime==1.32.0`、`numpy==2.5.5`、`Pillow==13.0.0`、`huggingface_hub==2.4.0`、`PyYAML==6.0.4`（コピーで動いた版）
- Modal の名前は forge の `APP_NAME = "illust-asset-forge"`・`VOLUME_NAME = "illust-asset-forge-models"` のまま
- 設定の誤りは `ConfigError("<相対パス>: <キーの位置>: <何がおかしいか>")`
- 書き出しは全部の入力（設定・元の絵・マスク）を検査してから書き始める
- `cutouts` が無いキャラクターの書き出しは今と同じ結果（顔は `export_size` の RGB、全身は写す）
- ゲーム側の事情（作品の画面の背景色、画面ごとの表示の大きさと名前、ゲームの名前）を forge に書かない
- コミットは Conventional Commits + 日本語の要約。push しない
- テスト: `.venv/bin/pytest`（今は 429 件すべて通る）

## Review Focus

1. 元の絵を差し替えたのに `cloud matte` を作り直していない → 書き出しが止まり、`python -m artgen.cloud matte <id>` を案内する（Task 5 の `test_export_stops_when_matte_is_older_than_source`）
2. 表情のマスクだけが古い → 顔も含めて何も書き換えない（Task 5 の `test_export_writes_nothing_when_one_variant_matte_is_stale`）
3. `cutouts` を消した・出力を減らした → 前の書き出しの RGBA・`-small`・確認図が残らず、今と同じ結果になる（Task 5 の `test_export_removes_outputs_of_removed_cutouts`）
4. 範囲・`erase` を直した、またはマスクを作り直したのに書き出していない → 承認用ページを作らない（Task 7 の `test_review_stops_when_config_changed_after_export`・`test_review_stops_when_matte_changed_after_export`）
5. 候補の背景消しが途中の区切りで落ちた → 済んだ区切りのマスクと回りの記録は残り、`page` でやり直すと残りだけ送る（Task 6 の `test_generate_shows_round_record_even_if_matte_fails` と Task 3 の `test_candidate_mattes_are_sent_in_batches_and_saved_per_batch`）

### Task 2: 設定 `cutouts` と `preview_background` を読む

**Files:**
- Modify: `src/artgen/config.py`
- Test: `tests/test_config.py`

**Interfaces:**
- Produces（`artgen.config`）:
  - `@dataclass(frozen=True) class ClearColor: min: int; max_rg: int; max_gb: int; min_rg: int | None = None`
  - `@dataclass(frozen=True) class CutoutOutput: suffix: str; box: tuple[int, int, int, int] | None; width: int | None`
  - `@dataclass(frozen=True) class Cutout: template: str; background: str; clear_colors: tuple[ClearColor, ...]; erase: tuple[tuple[tuple[int, int], ...], ...]; outputs: tuple[CutoutOutput, ...]`（`background` は `"matte" | "colors" | "none"`）
  - `Character.cutouts: dict[str, Cutout]`（キーはテンプレートの名前。書かなければ `{}`）。dataclass の最後に置き、既定値 `field(default_factory=dict)`
  - `load_preview_background(root: Path) -> str | None`（`defaults.yaml` の `preview_background`。`#rrggbb` の小文字・大文字どちらも可。無ければ `None`）

検査の決まり（全部 `ConfigError`、位置は `cutouts.<テンプレート>.<キー>`）:
- `cutouts` はキーと値の組。キーは `templates/<キー>.yaml` があること
- テンプレートごとのキーは `background`（必須）・`clear_colors`・`erase`・`outputs`（必須）だけ
- `background` は `matte`・`colors`・`none` のどれか
- `clear_colors` は `background: colors` のときだけ書ける。1 件は `{min, max_rg, max_gb}` と任意の `min_rg`、各 0〜255 の整数、`min_rg <= max_rg`（コピーの `_parse_face_crop` の検査と同じ）
- `erase` は `background: matte` のときだけ書ける。3 点以上の `[x, y]`（0 以上の整数）の多角形の一覧（コピーの `_parse_erase` と同じ）
- `outputs` は 1 件以上。1 件のキーは `suffix`（必須。`[A-Za-z0-9_-]*` に合う文字列）・`box`（任意。`null` か `parse_box`）・`width`（任意。`null` か正の整数）だけ。同じテンプレートの中で `suffix` が重ならない

### Task 5: 書き出しで `cutouts` を使う（`export.py`）

**Files:**
- Modify: `src/artgen/export.py`
- Test: `tests/test_export.py`

**Interfaces:**
- Consumes: Task 2・3・4
- Produces（`artgen.export`）:
  - `cutout_record(cutout: Cutout, source_dir: Path, names: list[str], matte_shas: dict[str, str] | None = None) -> dict` — `{"background", "clear_colors": [{min,max_rg,max_gb[,min_rg]}], "erase": [[[x,y],...]], "outputs": [{"suffix","box","width"}], "source_sha256": {名前: sha}}`。`background == "matte"` のときだけ `"matte_sha256": {名前: sha}`（`matte_shas` が無ければ今の `matte/` のファイルから求め、無いファイルは `None`）
  - `params.json` に `"cutouts": {テンプレート: cutout_record(...)}`（`cutouts` があるときだけ。無いキャラクターの `params.json` は今と同じ形）
  - 確認図: `local/check/<id>/<output_name(...)>`
  - `check_dir(root: Path, char_id: str) -> Path`（`root / "local" / "check" / char_id`）

流れ（コピーの `export_character` と同じ順。すべて検査してから書く）:
1. 元の絵ごとに今の検査（名前・条件・正方形）。`cutouts` に元の絵のテンプレートがあれば、各出力の `box` が絵の中かを見る（はみ出したら `ConfigError("characters/<id>/character.yaml: cutouts.<t>.outputs[<i>].box: 範囲 [...] が元の絵 <名前>（WxH）の外にはみ出す")`。正方形の検査は `export_size` のときだけで、`cutouts` のテンプレートでは見ない
2. 出力の名前と確認図の名前を `claim` で集め、重なれば `ExportError`
3. `matte` のテンプレートの元の絵は全部 `load_matte_with_sha` で読み、`prepared_mask` を済ませる
4. 消す: `characters/<id>/` の、今回の出力に無い、受け付ける名前（`_accepted_names`）とその `-` 付きの名前（今の `cutouts` に限らず、`<元の stem>-<任意>.png` のうち `<stem>` が受け付ける名前のもの）と、`local/check/<id>/` の PNG のうち今回の確認図に無いもの
5. 書く（`cutouts` が無いテンプレートは今と同じ）
